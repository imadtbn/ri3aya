# صيانة مكتبة المقالات

المصدر الوحيد للمقالات هو `content/articles/catalog.json`. ينتج `scripts/build_articles.py` صفحات HTML مستقلة، ومكتبة المقالات وسياسة التحرير وروابط الاكتشاف في الرئيسية والأقسام وفهرس البحث وخريطة الموقع. لا يحتاج عرض المقالات إلى JavaScript أو خدمة خلفية.

## إضافة مقال أو تحديثه

1. اختر رابطًا ثابتًا في `slug`، وأدخل العنوان والخلاصة والفئة العمرية والموضوع والصورة والنصوص.
2. تحقق من المصدر الرسمي. سجل عنوانه والجهة والرابط وتاريخ الصفحة الأصلية وتاريخ التحقق الفعلي. اربط كل قسم بمعرّفات مصادره.
3. أدخل تاريخ النشر والتحديث والتحقق التحريري بوظائفها المختلفة. حدّث تاريخ تعديل الفهرس `updated_at` عند تغيير محتوى المكتبة. لا تغيّر تاريخ النشر عند تعديل المقال، ولا تعتبر إعادة بناء الملفات تحققًا جديدًا من المصادر.
4. حدد `publication_status`: `draft` أو `published` أو `withdrawn`. المسودات والمقالات المسحوبة لا تدخل المكتبة أو البحث أو خريطة الموقع، ويزيل البناء صفحاتها المولدة.
5. تبقى `medical_review.status` بالقيمة `not_reviewed` ما لم توجد مراجعة فعلية. `pending` يعني انتظار المراجعة. عند `reviewed` يلزم اسم المختص ومؤهلاته وتاريخ المراجعة ورابط دليل يمكن التحقق منه؛ غياب أحدها يمنع البناء.
6. شغّل البناء ثم الفحوص التالية قبل رفع التعديل.

```bash
python -m pip install beautifulsoup4
python scripts/build_articles.py
python scripts/sync_layout.py --check
python scripts/build_articles.py --check
python scripts/check_article_library.py
python scripts/test_article_publication.py
python scripts/quality_gate.py
python scripts/check_site_tags.py
node scripts/test_search.cjs
```

يجب أن لا يغيّر إعادة البناء الملفات إذا لم يتغير المصدر. يحافظ البناء على المقالات الثابتة وروابطها، ويستبعد المسودات والمقالات المسحوبة من التوصيات أيضًا.

## التحقق في المتصفح

```bash
node scripts/check_layout.mjs
```

يتطلب Playwright ومتصفح Chromium مثبتين خارج الموقع الإنتاجي. يمكن تحديد مسار الحزمة عبر `PLAYWRIGHT_MODULE` ومسار المتصفح عبر `CHROMIUM_PATH`. يشمل الفحص جميع الصفحات recursively، وخمسة عروض، والبحث من مسار مقال متداخل، والتصفية، والقراءة دون JavaScript. يعزل خدمات CDN والتحليلات وService Worker، فلا يعد اختبار أداء خارجيًا أو مراجعة طبية.

المقالات الحالية ملخصات عربية بمساعدة آلية من CDC وWHO وNHS، بتاريخ تحقق 2026-10-11. جميعها تحمل حالة «لم يُراجع طبيًا بعد». لا تمنح إعادة النشر اعتمادًا طبيًا.

لصيانة تصنيف الأعمار والموضوعات وفهرس البحث، راجع `docs/search-maintenance.md`.
