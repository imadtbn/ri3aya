# تطوير موقع رعاية

## المرحلة 1 — تصحيح الأساس

التاريخ: 11 أكتوبر 2026.

- تصحيح نصوص رفع رأس السرير والنوم على البطن في الصفحة والنواتج البرمجية.
- استبدال واجهة تحليل الصوت غير المنفذة وادعاءات التشخيص بملخص ملاحظات ودليل طلب المساعدة؛ لا أذونات ميكروفون أو تحليل صوت.
- تحويل مساعد الأعراض إلى تنظيم ملاحظات مع التحقق من الحرارة؛ لا نتائج تلقائية أو درجات خطورة أو توصيات دوائية من الأداة.
- إصلاح FAQ وإزالة المستمع المكرر لقائمة المدونة؛ مطابقة حد القائمة المشتركة مع CSS الحالي.
- إصلاح رابط الأقسام، وربط بطاقات المدونة بالأدلة الموجودة، وتصحيح وعود ملفات PDF غير الموجودة.
- إزالة أرقام وبريد وعنوان الدعم التجريبية، وادعاءات الخبراء والاشتراك غير المفعّل.
- النموذج ينسخ مسودة محلية مع بديل يدوي، يحتفظ بالمدخلات، ويصرح أنه لا يرسل رسالة. يلزم إدخال قناة استقبال حقيقية لاحقًا.
- عرض أسماء الأطعمة المدخلة كنصوص، وتحديث فهرس البحث من المحتوى الحالي، ورفع إصدار Service Worker.
- توسيع فحص الجودة للروابط المحلية والنصوص غير الآمنة المكتشفة.

التحقق: فحص الجودة لـ21 صفحة، فحص الوسوم لـ22 صفحة، فحص JavaScript وJSON والفرق، وتهيئة 21 صفحة في محاكاة DOM مع اختبارات الوظائف المعدلة. محاكاة DOM تستبعد المكتبات الخارجية؛ لا تعادل قياس الأداء أو اختبار هاتف فعلي.

المصادر التحريرية: [CDC — النوم الآمن](https://www.cdc.gov/sudden-infant-death/sleep-safely/index.html)، [NHS — الطفل الباكي](https://www.nhs.uk/conditions/baby/first-year/baby-basics/soothing-a-crying-baby/)، [الحماية المدنية الجزائرية](https://dgpc.dz/).

هذه تصحيحات تحريرية وتقنية وليست اعتمادًا طبيًا من مختص. يلزم مراجعة طبيب أطفال للمحتوى الحساس قبل وصف المنصة بأنها مرجع طبي معتمد.

## المرحلة 2 — توحيد التصميم

التاريخ: 11 أكتوبر 2026. دُمج الطلب #1 ونُشرت المرحلة الأولى بنجاح عبر GitHub Pages.

- توحيد الرأس، الهوية، مقدمة الصفحة، مسار التنقل والتذييل في الصفحات العامة الـ21، مع إبقاء المقالات ومعرّفات الأدوات.
- توليد القالب الثابت باستخدام `scripts/sync_layout.py` بدل الاعتماد على JavaScript لعرض التنقل. الأمر `--check` يتحقق من التزام الصفحات بالقالب، وهو جزء من CI.
- تصميم RTL بألوان ومسافات وأزرار وبطاقات متسقة؛ تخطيط جانبي للمقالات على الحاسوب وعمود واحد على الهاتف.
- تحميل CSS المشترك وأنماط الصفحة نفسها فقط؛ إزالة التكرار و4 ملفات ترقيعات قديمة غير مستخدمة، وتوحيد متغيرات CSS وأنماط البحث.
- إظهار البحث على الهاتف، والبحث أثناء الكتابة، وتجاهل التشكيل والتطويل والاختلافات الشائعة للألف والياء والتاء المربوطة. البحث متعدد الكلمات عبر فهرس المحتوى الحالي.
- التنقل بالأسهم وEscape في النتائج والقائمة، وإعادة التركيز، وفصل رابط الأقسام عن زر فتح موضوعاتها. حماية النتائج من وصول استجابة قديمة بعد الإغلاق، وإتاحة إعادة المحاولة بعد فشل الفهرس.
- تحديث Service Worker لتجديد التخزين المؤقت عند النشر.

التحقق: فحص الجودة والوسوم وتطابق القالب والفرق، واجتياز اختبارات المرحلة الأولى لمحاكاة DOM. في Chromium: 105 فحوص للصفحات الـ21 عند العروض 360 و390 و768 و1024 و1440، دون تمرير أفقي أو أخطاء JavaScript محلية. اختبارات تفاعل فعلية للقائمة على الهاتف، لوحة المفاتيح، البحث العربي في صفحة ذات مسار متداخل، النتائج الفارغة، المسح، والاستجابة المتأخرة. فُحصت صور العرض للرئيسية على الهاتف والحاسوب.

اختبارات المتصفح قابلة للإعادة عبر `scripts/check_layout.mjs` باستخدام Playwright؛ لا يُضاف إلى اعتماديات الموقع الإنتاجية. تعزل هذه الاختبارات خدمات التحليلات والخطوط والمكتبات الخارجية وتمنع Service Worker لضمان اختبار الملفات الحالية؛ لا تمثل قياس Core Web Vitals أو اختبار أجهزة فعلية أو اعتمادًا للمحتوى الطبي.

## المرحلة 3 — مكتبة المقالات المستقلة

التاريخ: 11 أكتوبر 2026.

- إنشاء 5 مقالات بروابط ثابتة في `pages/articles/`: النوم الآمن، الطعام التكميلي، الاستحمام، منطقة الحفاض وتهدئة البكاء.
- قالب عربي يشمل الخلاصة، الفئة العمرية، فهرس المحتويات، أقسامًا بإحالات إلى المصادر، حدود العناية وطلب المساعدة، ومقالات ذات صلة.
- إظهار تاريخ النشر والتحديث والتحقق التحريري وحالة النشر والمراجعة الطبية. جميع المقالات الحالية «لم يُراجع طبيًا بعد»؛ لا أسماء أطباء أو تواريخ اعتماد افتراضية.
- التحقق من 6 مصادر رسمية لدى CDC وWHO وNHS، وتسجيل تاريخ المصدر وتاريخ الاطلاع منفصلين. الصياغة بمساعدة آلية وليست ترجمة رسمية أو مراجعة سريرية.
- إنشاء سياسة تحرير ومراجعة، ومصدر بيانات واحد لتوليد المقالات والمكتبة والرئيسية وروابط الأقسام والبحث وخريطة الموقع. المسودات والمقالات المسحوبة لا تدخل الاكتشاف العام.
- استبدال بطاقات المدونة التجريبية وتواريخها القديمة ببطاقات المقالات الفعلية. التصفية الأساسية حسب الموضوع تعمل مع عدد نتائج معلن.
- دعم البحث والتنقل من مسارات المقالات المتداخلة، ووسوم Article/CollectionPage بمصادر وتواريخ صحيحة دون ادعاء اعتماد طبي.
- إضافة فحوص CI لتطابق البناء وسلامة بيانات النشر والمراجعة والمصادر والروابط، وتحديث Service Worker.

التحقق: فحص الجودة لـ27 صفحة، وفحص الوسوم لـ28 صفحة، وتطابق البناء والقالب، وفحص بيانات المقالات والمصادر والتواريخ وخريطة الموقع والبحث. اجتازت 27 صفحة 135 فحص عرض في Chromium عند 360 و390 و768 و1024 و1440 بكسل، مع اختبارات التصفية والبحث من المقالات المتداخلة والقراءة دون JavaScript. فُحص عرض المكتبة والمقال بصريًا. في نسخة اختبار معزولة، رُفض ادعاء مراجعة طبية بلا بيانات اعتماد، واستُبعد مقال مسودة، ثم سُحبت جميع المقالات دون بقاء روابطها في الاكتشاف العام. هذه الفحوص تعزل خدمات CDN والتحليلات وService Worker، وليست مراجعة طبية أو اختبار أجهزة فعلية.

دليل الصيانة: `docs/article-authoring.md`. المقالات والمكتبة متاحة كـHTML ثابت دون اعتماد على JavaScript لقراءة المحتوى.

## المرحلة 4 — البحث والفلترة حسب العمر والموضوع

التاريخ: 11 أكتوبر 2026. بُنيت على المرحلة الثالثة المدمجة في `main`.

- صفحة بحث موحدة `pages/search.html` للمقالات والأدلة والأدوات، مع فلترة الموضوع ونوع المحتوى وعمر الطفل بالأشهر المكتملة من 0 إلى 36.
- تحسين مطابقة العربية بإهمال التشكيل والتطويل وتوحيد بعض الحروف وأداة التعريف، ودعم مرادفات مثل التلقيح والتطعيم والحفاضات. تجتمع كلمات البحث والفلاتر ولا يجري استنتاج أعراض أو تشخيص.
- اقتراحات الرأس محدودة بـ8 نتائج مع رابط إلى البحث الكامل؛ الإرسال وEnter يفتحان صفحة البحث من أي مسار، بما في ذلك المقالات المتداخلة.
- عرض 8 نتائج أولًا ثم المزيد، وعدد النتائج والتحميل والنتائج الفارغة والخطأ وإعادة المحاولة. الفهرس القديم يُرفض بدل عرض نتائج عمرية مضللة.
- حفظ البحث والفلاتر في الرابط، واستعادتها عند إعادة الفتح والرجوع في المتصفح، ونسخ الرابط مع بديل يدوي عند رفض الحافظة. العمر صفر محفوظ صراحة.
- توسيع مكتبة المقالات ببحث نصي وفلتر العمر إلى جانب الموضوع، مع بقاء المقالات والروابط قابلة للقراءة دون JavaScript.
- مصدر مستقل لبيانات اكتشاف الأدلة والأدوات في `content/search/catalog.json`، وفهرس بالإصدار 4، وتحديث التخزين المؤقت في Service Worker.

فلتر العمر يعتمد على النطاق المعلن في المحتوى فقط، ولا يمثل تقييمًا طبيًا أو توصية ملاءمة شخصية. الأدلة العامة بلا نطاق محدد تُعرض عند إلغاء فلتر العمر؛ لا تُنسب إليها أعمار مفترضة. لم تتغير حالات المراجعة الطبية للمقالات.

التحقق: فحوص الجودة والبناء والقالب والوسوم والمقالات والنشر، واختبارات Node للبحث العربي وتقاطعات الفلاتر والحدود العمرية والروابط. اجتازت 28 صفحة 140 فحص عرض في Chromium، مع اختبارات الاقتراحات ولوحة المفاتيح والمسارات المتداخلة والتصفية والترقيم وروابط المشاركة والرجوع والحافظة وبديلها والخطأ وإعادة المحاولة والاستجابات المتأخرة. فُحص عرض البحث على الهاتف والحاسوب بصريًا. هذه الفحوص تعزل خدمات CDN والتحليلات وService Worker، وليست اختبار أجهزة فعلية أو أداء خارجيًا أو اعتمادًا طبيًا.

دليل الصيانة: `docs/search-maintenance.md`.

## المرحلة 5 — أدوات المتابعة المحلية وإدارة البيانات

التاريخ: 11 أكتوبر 2026. بُنيت على المرحلة الرابعة المدمجة في `main`.

- طبقة تخزين مشتركة `js/local-data.js` لسجلات النمو والطعام وملاحظات الأعراض والروتينات. تستعمل المفاتيح القديمة دون نقل أو حذف، وتتحقق من بنية البيانات قبل استخدامها.
- إيقاف الاقتصاص الصامت إلى آخر 15 طعامًا و10 سجلات أعراض. لا تحذف الأدوات الأقدم تلقائيًا؛ الحد الحالي 1000 سجل أو 2 ميجابايت لكل أداة، مع السماح بتقليل سجل قديم يتجاوز الحد.
- لوحة لإدارة سجلات المتابعة الأربعة في صفحة الأدوات، ولوحة لكل أداة قرب سجلها، مع العدد والحجم التقريبي والتحديث اليدوي.
- تصدير JSON لكل أداة أو لجميع السجلات الأربعة، وتصدير CSV لكل أداة بترميز عربي وحماية النصوص التي قد تُفسّر كصيغ. يتضمن JSON نتائج القياسات ومرجعها كما حُفظت، دون إعادة حساب أو اعتماد جديد.
- حذف قياس أو طعام أو ملاحظة أو روتين منفرد، وحذف سجل أداة أو جميع سجلات المتابعة بعد التأكيد. لا يُستخدم `localStorage.clear()` ولا يُمسح غير المفاتيح الأربعة المعلنة.
- إظهار خطأ صريح عند تعذر القراءة أو امتلاء التخزين أو فشل الحذف؛ لا تعرض الواجهة نجاحًا وهميًا، ولا تمسح مدخلات الطعام عند فشل الحفظ. البيانات التالفة تُحفظ كما هي مع خيار نسخة خام قبل الحذف.
- تحديث القوائم عند تغييرات تبويب آخر وقراءة أحدث السجلات قبل الإضافة والحذف، بدل الاعتماد على مصفوفات مخزنة في الذاكرة.
- عرض الروتينات المحفوظة وإعادة فتحها وحذفها؛ حماية عرض النصوص المحفوظة، وإتاحة نسخ الروتين يدويًا عند رفض الحافظة.
- اختيار جنس المرجع بصورة مستقلة عند حفظ قياس النمو وإظهاره في السجل، وإصلاح إعلان UTF-8 المفقود في صفحة النمو. تبقى المؤشرات تثقيفية، ولا تتغير المصادر الطبية أو حالات مراجعة المقالات.
- تحديث بيان الخصوصية ليصف التخزين المحلي والخدمات المتصلة فعليًا، وإزالة وعود الحسابات والنسخ الاحتياطي والاتصال التجريبية. تحديث إصدار Service Worker وفحوص CI.

التخزين مرتبط بالمتصفح والأصل، وليس حسابًا أو نسخة احتياطية دائمة، ولا توجد مزامنة أو استيراد ملفات في هذه المرحلة. التصدير غير مشفر، والحذف لا يزيل الملفات التي نزلتها أو بيانات متصفحات أخرى. الحجم المعروض يخص محتوى السجلات فقط، ولا يمثل حصة التخزين الكلية للمتصفح.

التحقق: نجحت فحوص الجودة والبناء والقالب والمقالات والنشر والوسوم والبحث، واختبارات التخزين في Node. اجتازت الصفحات الـ28 عدد 140 فحص عرض في Chromium، مع فحص ملفات التصدير التي نزلت فعليًا والحذف مع الإلغاء والتأكيد، وإعادة التحميل والروتينات والنسخ اليدوي وتحديث النافذة الثانية ورفض التخزين في صفحات الأدوات الخمس. فُحصت لوحة الإدارة بصريًا على الهاتف والحاسوب. تعزل الاختبارات خدمات CDN والتحليلات وService Worker، وليست اختبار هاتف فعلي أو أداء خارجيًا أو مراجعة طبية.

دليل الصيانة: `docs/local-data-maintenance.md`. فحوص التخزين القابلة للإعادة: `node scripts/test_local_data.cjs`، وفحوص المتصفح ضمن `scripts/check_layout.mjs`.
