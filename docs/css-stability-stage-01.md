# المرحلة 01 — تدقيق واستعادة استقرار التصميم

تاريخ المراجعة: 2026-10-12

## النطاق

جرى فحص ملفات HTML لعينة من 20 صفحة (الرئيسية، الأقسام، النوم، التغذية، البكاء، النمو، التلقيح، الاستحمام، الحفاضات، الجهاز الهضمي، الأمراض، النصائح، المقالات، البحث، الأدوات، الأسئلة الشائعة، المصادر والسياسات)، مع مراجعة CSS العام والمتخصص.

### مصادر CSS المؤثرة

- `css/main.css`: أنماط قديمة للبطاقات والصور والزر العائم.
- `css/responsive.css`: قواعد الهاتف وأزرار التنقل العامة.
- `css/site-polish.css`: القشرة البصرية المشتركة، مُحمّلة بعد الأنماط الخاصة.
- `css/nutrition.css`, `css/improvements-crying.css`: تخطيط أصلي من نوع flex لمحتوى الدليل والشريط الجانبي.
- `css/articles.css`: بطاقات المكتبة والقارئ وتنسيقات الهاتف.
- `css/accessibility.css`: التركيز والتنقل والجداول.

تنبيه: كثرة ملفات CSS وحدها ليست خطأ؛ المشكلة كانت أسبقية القواعد واسعة النطاق.

## التعارضات والإصلاحات

| المكوّن | قبل الإصلاح | بعد الإصلاح | سبب التغيير |
|---|---|---|---|
| بطاقة أقسام الرئيسية المصورة | `.site-shell .sections-grid .section-card {padding:28px}` | الحشوة الإضافية مطبقة فقط على `body.sections-page .sections-grid > .section-card` | الحفاظ على الصورة الملاصقة لحواف بطاقة الرئيسية الأصلية |
| بطاقات صفحة الأقسام | نفس قاعدة الرئيسية عامة | قاعدة مقيدة بصفحة الأقسام | منع تداخل تصميم الصفحة مع بطاقات الرئيسية |
| التغذية والبكاء | `.site-shell .content-wrapper{display:grid}` يتجاوز `display:flex` الخاص بالصفحة | `preserve-legacy-layout` يستخدم الآن Grid بمحتوى واسع وشريط جانبي ثابت 280px | منع ضيق النصوص والطول الرأسي المفرط بسبب تمدد الشريط الجانبي |
| عمود الدليل على الكمبيوتر | `.site-shell .sidebar{position:static}` يلغي sticky الأصلي | sticky في الصفحتين المقصودتين فقط بعرض أكبر من 992px | الحفاظ على وظيفة الشريط الجانبي |
| زر العودة للأعلى | CSS يخفي `i.fa-chevron-up` ويستبدلها بالرمز ↑ | إظهار الأيقونة الأصلية، والاحتفاظ بالبديل عند عدم وجود عنصر `i` | عدم طمس أيقونات الواجهة الأصلية |
| الهاتف <= 992px | قد يبقى العمود الجانبي بجانب النص | عمود واحد بنظام Grid والشريط غير مثبت | منع ازدحام عرض الهاتف |

## التغييرات

- `css/site-polish.css`: قصر قواعد الأقسام العامة على صفحة الأقسام، وإرجاع الأيقونة وتعريف تخطيط محلي محدد.
- `pages/nutrition.html` و`pages/crying.html`: إضافة فئة وصفية للتخطيط المقصود.
- `pwa/config.js` و`service-worker.js`: تحديث إصدار ذاكرة التخزين بعد تغييرات CSS.
- `scripts/visual_compare.mjs`: أداة التقاط صور وقياسات قبل/بعد، دون التأثير على الشيفرة الإنتاجية.

## إنشاء مقارنة بصرية حقيقية للصفحات

الأداة تتطلب نسختين محليتين كاملتين للملفات ومتصفح Chromium عبر Playwright:

```bash
gh repo clone imadtbn/ri3aya
cd ri3aya
git worktree add ../ri3aya-before 61bd7c875366e1a4449412fd37ed3beefede45bb
npm install --no-save playwright
node scripts/visual_compare.mjs --before-root=../ri3aya-before --after-root=. --out=visual-report
```

إذا كان Chromium مثبّتًا بالنظام استخدم `CHROMIUM_PATH=/usr/bin/chromium`.
افتح `visual-report/index.html` لرؤية صور أفقية قبل/بعد وعرض المقاييس من `visual-report/metrics.json`.

تغطي المقارنة: الرئيسية، الأقسام، التغذية، البكاء، النوم، الأدوات، النمو، التلقيح، المقالات، ونموذج مقال مستقل، على عرضَي 390 و1440 بكسل.

اللقطات لا تُدّعى موجودة حتى يكتمل تشغيل أداة المقارنة فعليًا. تعذر الاستنساخ واختبار المتصفح من بيئة تنفيذ المراجعة بسبب عدم توفر الوصول الشبكي إلى GitHub، لذا يُعد اختبار المقارنة البصرية خطوة قبول معلقة.

## شروط اعتماد المرحلة

1. تشغيل `node scripts/check_layout.mjs` بنجاح مع Playwright؛ يشمل الاختبار عرض 320، 360، 390، 768، 1024، 1440 بكسل.
2. مراجعة تقرير المقارنة المرئية والتأكد من عدم اختفاء الصور أو الألوان أو الأزرار.
3. فتح وإغلاق قائمة الهاتف والقائمة الفرعية على الصفحات المتخصصة.
4. التأكد من ثبات أقسام الصفحة والروابط والصور والبيانات المحلية بعد تحديث PWA.
5. توثيق أي فرق بصري غير مقصود وتصحيحه قبل اعتماد المرحلة.

## تصحيح لاحق — ارتفاع صفحتي التغذية والبكاء (2026-10-12)

أثبت فحص CSS أن `flex: 2 1 0` للمحتوى و`flex: 1 1 300px` للشريط الجانبي يسمحان للشريط باستهلاك حصة كبيرة من مساحة الكمبيوتر. يزيد التفاف نص المقال ويطيل الصفحة، رغم أن المحتوى لم يتغير.

استُبدل بهما تخطيط Grid بعمود محتوى `minmax(0, 1fr)` وشريط جانبي 280px. تحت 992px يصبح عمودًا واحدًا، وتحت 600px تقل الفراغات الداخلية المحددة فقط دون حذف أو إخفاء محتوى. تمت إضافة حماية من عودة قيم flex السابقة في `scripts/check_css_stability.mjs`، وتحديث إصدار PWA إلى `guide-width-fix-20261012-v2`.

التحقق من المصدر البرمجي ناجح؛ قياس الارتفاع المرئي والتقاط لقطات صفحات حقيقية ما زالا من متطلبات القبول.
