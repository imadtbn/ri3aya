# صيانة سجلات المتابعة المحلية

## النطاق ومصدر الحقيقة

المصدر هو التخزين المحلي نفسه. تشترك الأدوات في `js/local-data.js`، وتستخدم المفاتيح القائمة:

| الأداة | المفتاح | الصفحة |
| --- | --- | --- |
| النمو | `ri3aya-growth-tracker` | `pages/growth.html` |
| الطعام | `foodRecords` | `pages/nutrition.html` |
| ملاحظات الأعراض | `symptomRecords` | `pages/digestive.html` |
| الروتينات | `saved_routines` | `pages/tools/routine.html` |

لا تستخدم `localStorage.clear()`. التفضيلات والنصائح المحفوظة وقائمة الحفاضات وملفات PWA ليست ضمن الحذف الجماعي. GitHub Pages يشارك أصل المتصفح بين مشاريع المالك، لذلك لا تمس مفاتيح غير معلنة.

## التعامل مع الفشل

`Ri3ayaLocal.read/add/removeRecord/clear` تعيد نتيجة بـ`ok` ورسالة عربية عند الخطأ. لا تغيّر الواجهة أو تفرغ الحقول على أساس نجاح لم يحدث. الإضافة والحذف يقرآن البيانات الحالية؛ استمع إلى `ri3aya-data-change` لتحديث القوائم عند الكتابة المحلية أو حدث `storage` في تبويب آخر. لا توجد معاملة متعددة المفاتيح: الحذف الجماعي يعلن أسماء الأدوات التي تعذر حذفها إذا حدث نجاح جزئي. الأحداث لا تضمن قفل كتابتين متزامنتين في تبويبين؛ لا تقدم وعدًا بمزامنة متعددة المستخدمين.

البيانات غير الصالحة أو JSON التالف لا يتحولان تلقائيًا إلى سجل فارغ ولا يجري الكتابة فوقهما. تتيح اللوحة تصدير قيمة المفتاح الأصلية داخل ملف نسخة خام قبل الحذف. السجلات القديمة بلا نتائج نمو أو جنس تُعرض مع بيان نقص المعلومات دون اختلاق حساب سابق.

الحد لكل أداة 1000 سجل أو 2 ميجابايت من UTF-8 JSON. الإضافة التي تتجاوز الحد تُرفض دون إسقاط أقدم سجل؛ يمكن تصدير السجل وحذف سجلات منه. يسمح الحذف بتقليل بيانات قديمة فوق الحد حتى لو ظلت أعلى منه.

## التصدير والعرض

- JSON يحمل `format: ri3aya-local-follow-up` و`version: 1` ووقت التصدير و`records` بحسب المفاتيح. يحتفظ بالتفاصيل ونتائج WHO وبيانات المصدر كما حُفظت.
- CSV يحمل BOM لـUTF-8 وخلايا مقتبسة، مع حفظ الأسطر والاقتباسات وتحويل المداخل التي تشبه الصيغ إلى نصوص. القيم المركبة تُكتب كـJSON في الخلية.
- النسخة الخام تحمل `format: ri3aya-local-raw` و`version: 1` و`raw`؛ ليست ملف استيراد تلقائيًا.
- التنزيل يبدأ محليًا، ولا يرسل الملف إلى خادم. لا توجد مزامنة أو تشفير خاص أو استيراد في هذه المرحلة. لا تصف الملفات بأنها نسخة احتياطية مستعادة تلقائيًا.
- اعرض المحتوى بـ`textContent`، أو هربه قبل إدخاله في قالب HTML كما في سجل النمو والروتين. لا تضع قيمة محفوظة في HTML دون معالجة.

لوحات الإدارة الثابتة وأنماطها وتحميل السكريبت يولدها `scripts/sync_layout.py`. بعد تغيير بيانات أو نصوص الصفحات أعد توليد فهرس البحث باستخدام `scripts/build_articles.py`.

## التحقق

```bash
python scripts/sync_layout.py
python scripts/build_articles.py
python scripts/sync_layout.py --check
python scripts/build_articles.py --check
python scripts/quality_gate.py
node scripts/test_local_data.cjs
node scripts/test_search.cjs
node scripts/check_layout.mjs
```

اختبارات Node تتحقق من السجلات القديمة والعمر صفر والتلف والحصة والفشل وحماية CSV وحذف المفاتيح المعلنة. اختبار Playwright ينزل الملفات ويفحص محتواها، ويختبر الحذف مع الإلغاء والتأكيد، وإعادة التحميل والروتينات والنافذة الثانية والتخزين الممنوع. يحتاج Playwright وChromium خارج اعتماديات الإنتاج ويدعم `PLAYWRIGHT_MODULE` و`CHROMIUM_PATH`. تعزل هذه الفحوص الخدمات الخارجية وService Worker، ولا تعادل اختبار هاتف فعلي أو أداء خارجيًا أو مراجعة طبية.
