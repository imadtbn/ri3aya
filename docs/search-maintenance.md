# صيانة البحث والفلترة

تُولد صفحة البحث وفهرس `search/index.json` من `scripts/build_articles.py`. لا تعدّل الملفات المولدة مباشرة. يستخدم الرأس وصفحة البحث والمكتبة محركًا مشتركًا في `js/search-core.js`.

## بيانات الاكتشاف

- المقالات: `content/articles/catalog.json`. ينتج البناء نطاق العمر والموضوع ونوع `article` وحالة المراجعة من بيانات المقال المنشور فقط؛ المسودات والمسحوبات مستبعدة.
- الأدلة والأدوات والصفحات: `content/search/catalog.json`. المفتاح هو المسار المحلي؛ حدد النوع والموضوعات والخلاصة الدلالية في الكلمات الإضافية. النص والعنوان والخلاصة الرئيسية تأتي من HTML.
- قاموس الموضوعات في `topics` يتكون من معرّف ثابت وعنوان عربي. استخدم المعرّف نفسه في سجلات المحتوى. تصنيف المكتبة العام مثل `safety` يبقى ضمن موضوعات المقال لتوافق فلاتر المكتبة.
- الأدلة العامة تستخدم `age_scope: general` وعمرين `null`. لا تخمّن عمرًا لجعلها تظهر في النتائج.
- النطاق المعلن يستخدم `age_scope: range` و`age_min_months` و`age_max_months` و`age_label`. تحقق أن الحدود مطابقة للمحتوى؛ الحد الأدنى والأقصى شاملان. لا يشير النطاق إلى مراجعة طبية أو توصية شخصية.
- حدّث `updated_at` عند تغيير بيانات الاكتشاف، دون تغيير تواريخ مراجعة المقالات لمجرد إعادة البناء.

## البحث والروابط

الفهرس يحمل `schema_version: 4`. ترفض الواجهة إصدارًا مختلفًا وتتيح إعادة المحاولة. لا تضف سجلًا لصفحة البحث إلى فهرس نفسها.

المعاملات هي `q` و`age` و`topic` و`type`؛ العمر عدد صحيح من 0 إلى 36 بالأشهر المكتملة. القيم غير الصالحة تُزال، والعمر صفر يُحفظ. تتقاطع جميع الفلاتر، وتُستبعد الأدلة بلا نطاق محدد عندما يختار المستخدم عمرًا. دون كلمات بحث تُخفى الصفحات الإدارية، إلا عند اختيار نوع الصفحات صراحة.

تُعرض 8 نتائج ثم زر المزيد. يدعم المحرك كلمات عربية متعددة وتوحيد الحروف وإزالة التشكيل وأداة التعريف وبعض المرادفات التحريرية؛ لا يوسع البحث إلى استنتاجات تشخيصية. عند إضافة مرادفات إلى `js/search-core.js` أضف حالات مفيدة إلى `scripts/test_search.cjs`.

الفلاتر محفوظة في الرابط وليست ملفًا للطفل أو سجل متابعة. القراءة والتنقل متاحان دون JavaScript؛ التصفية التفاعلية تحتاجه.

## البناء والتحقق

```bash
python scripts/build_articles.py
python scripts/build_articles.py --check
python scripts/sync_layout.py --check
python scripts/quality_gate.py
python scripts/check_article_library.py
python scripts/test_article_publication.py
node scripts/test_search.cjs
node scripts/check_layout.mjs
```

اختبار المتصفح يتطلب Playwright وChromium خارج اعتماديات الإنتاج، ويدعم `PLAYWRIGHT_MODULE` و`CHROMIUM_PATH`. يفحص الحدود العمرية والمشاركة والرجوع والنسخ وبديل الحافظة وفشل الفهرس وإعادة المحاولة والاستجابات المتأخرة، مع فحص الصفحات عند خمسة عروض. يعزل الخدمات الخارجية وService Worker.
